# 🎬 App de Filmes

Projeto de um Catálogo de filmes no lançamento, utilizando React, TypeScript, Vite, Tailwind CSS e bibliotecas de animação como [Motion](https://motion.dev/) e [React Bits](https://reactbits.dev/). Para obter as informações do catálogo, foi utilizado a API [TMDB](https://www.themoviedb.org).

## 💻 Tecnologias

- React;
- TypeScript;
- Tailwind CSS;
- Motion;
- React Bits;
- React Spinners;
- Vite;
- API TMDB;
- Responsividade.

## 🔧 Instruções de Instalação

### Pré-requisito: instale o [Node.js](https://nodejs.org/pt-br), recomenda-se a versão LTS.

---

Para executar o projeto localmente, siga os passos abaixo.

### 1. Clone o repositório

Abra a pasta em que deseja clonar o repositório e coloque o seguinte prompt no terminal:

```bash
git clone https://github.com/DanielsSon12/appFilmes_project.git
```

### 2. Acesse a pasta do projeto

```bash
cd appFilmes_project
```

### 3. Instale as dependências

Abra o terminal no projeto e digite:

```bash
npm install
```

### 4. Execute o projeto

Abra o terminal no projeto novamente e digite:

```bash
npm run dev
```

Após executar o comando, o Vite disponibilizará o projeto localmente. Acesse o endereço exibido no terminal, normalmente:

```bash
http://localhost:5173
```
